# 소크라테스 — 누구든 함께 만드는 소크라테스

되묻는 대화 상대. 사람이 생각을 말하면, 소크라테스는 답을 주지 않고 목적을 가지고 되묻는다.
그리고 이 소크라테스는 한 사람이 만들지 않는다. 누구든 그의 마음을 읽고, 고칠 점을 제안하고, 문답을 나누어 함께 만든다.

시작(2026-11-22, 원장님):
- "소크라테스 앱을 하나 만들어야겠어!"
- "소크라테스는 질문을 하는데 그냥 질문을 하는 것이 아니지? 목적을 가지고 질문을 하는 것이지?"
- "이 앱은 누구든 참여해서 함께하여 소크라테스를 만드는 프로젝트야!"

## 소크라테스는 왜 묻나

상대가 자기 생각을 스스로 검토하게 하려고 묻는다. 이기려고 묻지 않는다.
핵심 말을 붙잡고("X란 무엇인가") → 작은 동의를 하나씩 얻고 → 동의들이 처음 생각과 부딪히는 것을 상대가 보게 하고 → 다시 정의하게 하고 → 막히면(아포리아) 그것을 시작으로 삼는다.

이것이 소크라테스의 마음(지시문)이다. 첫 판은 [소크라테스.md](소크라테스.md).

## 함께 만드는 법

| 무엇 | 어디서 | 누가 정하나 |
|---|---|---|
| 마음을 함께 고친다 | 「소크라테스의 마음」 탭에서 지금 판을 읽고 제안한다 | 원장님이 읽고, 받아들이면 새 판이 된다 |
| 답마다 한마디 | 소크라테스의 답 아래 「소크라테스다웠나? 그렇다 · 아니다」 + 한마디 | 원장님이 모아 읽고 고칠 데를 찾는다 |
| 문답집 | 문답을 두 번 이상 주고받으면 「문답집에 올리기」 | 원장님이 골라 싣는다 |
| 코드 | 이 저장소 | 원장님 |

원장님이 제안을 받아들일 때는 「마음에 넣어 보기」를 누른다. Claude가 제안의 뜻을 살려 고칠 곳만 고친 초안을 쓰고, 바뀌는 곳을 보여 준다. 원장님이 읽고 고친 뒤 「새 판으로 받아들이기」를 누르면 소크라테스의 마음이 바뀐다. 지나간 판은 지우지 않고 「마음의 역사」에 남는다(누구의 제안으로, 무엇이 바뀌었나).

## 자리

| 것 | 자리 |
|---|---|
| 첫 판의 마음 | `소크라테스.md` (처음 켤 때 `data/마음/0001.md` 로 옮겨진다) |
| 서버 | `server.mjs` (Node 22, 바깥 틀 없이 `node:http` 와 `@anthropic-ai/sdk`) |
| 모두의 화면 | `public/index.html` — 문답 · 소크라테스의 마음 · 문답집 |
| 원장님 화면 | `public/admin.html` — 주소 `/admin` |
| 쌓이는 것 | `data/` (git 에 안 올린다) — 대화/ · 마음/ · 제안/ · 문답집/ · 한마디.jsonl · 쓴것.jsonl |
| 열쇠 | 맥 `~/열쇠/열쇠.env` 의 `ANTHROPIC_API_KEY` (저장소에 두지 않는다) |

## 켜기

```
cd ~/socrates && npm install && ./켜기.sh
```

그다음 http://127.0.0.1:7970 (모두의 화면), http://127.0.0.1:7970/admin (원장님 화면).
`SOCRATES_ADMIN_PASSWORD` 가 없으면 원장님 화면은 서버가 도는 컴퓨터에서만 열린다.

| 환경 변수 | 뜻 | 기본 |
|---|---|---|
| `PORT`, `HOST` | 듣는 곳 | 7970, 127.0.0.1 |
| `SOCRATES_EFFORT` | 생각의 깊이 low · medium · high | medium |
| `SOCRATES_ADMIN_PASSWORD` | 원장님 화면 비밀번호 | 없음(이 컴퓨터에서만) |
| `SOCRATES_PASSWORD` | 모두에게 문 비밀번호(좁게 열 때) | 없음 |
| `SOCRATES_TRUST_PROXY` | 캐디 같은 앞문 뒤에 설 때 1 | 없음 |
| `SOCRATES_DAILY_PER_PERSON` | 한 사람(주소)이 하루에 받는 답 수 | 100 |
| `SOCRATES_DAILY_TOTAL` | 모두 합쳐 하루 답 수 | 1500 |
| `SOCRATES_DATA` | 쌓이는 곳 | ./data |

## 두뇌

- 모델 `claude-opus-5-5`, 생각 깊이 medium, 스트리밍.
- 거절되면 다른 모델로 이어 가게 했다(`fallbacks: "default"`).
- 마음(시스템 글)은 캐시해서, 두 번째 말부터는 싸고 빠르다.
- 11/22 시험: 한 번 답에 3~6초, 출력 200~500 토큰(한 번에 1~2센트). 제안 초안은 20초쯤.
