# 소크라테스

되묻는 대화 상대. 사람이 생각을 말하면, 소크라테스가 답을 주지 않고 목적을 가지고 되묻는다.
원장님이 "소크라테스 앱을 하나 만들어야겠어!"라고 하신 데서 시작했다(2026-11-22).

정한 것(11/22 원장님):
- 무엇: 되묻는 대화 상대(문답법)
- 누가: 원장님과 다른 사람도
- 어디서: 웹 페이지

## 소크라테스는 왜 묻나

그냥 묻지 않는다. 상대가 자기 생각을 스스로 검토하게 하려고 묻는다.
핵심 말을 붙잡고("X란 무엇인가") → 작은 동의를 하나씩 얻고 → 동의들이 처음 생각과 부딪히는 것을 상대가 보게 하고 → 다시 정의하게 하고 → 막히면(아포리아) 그것을 시작으로 삼는다.

이 길과 말투는 모두 [소크라테스.md](소크라테스.md)에 있다. 소크라테스를 바꾸고 싶으면 이 글을 고치고 서버를 다시 켠다.

## 자리

| 것 | 자리 |
|---|---|
| 소크라테스의 마음(지시문) | `소크라테스.md` |
| 서버 | `server.mjs` (Node, 바깥 틀 없이 `node:http` 하나) |
| 화면 | `public/index.html` (한 장) |
| 쌓인 대화 | `data/<문답번호>.json` (git 에 안 올린다) |
| 쓴 양 | `data/쓴것.jsonl` (한 번 답할 때마다 토큰 수 · 걸린 시간) |
| 열쇠 | `~/열쇠/열쇠.env` 의 `ANTHROPIC_API_KEY` (여기 두지 않는다) |

## 켜기

```
cd ~/socrates && ./켜기.sh
```

그다음 브라우저에서 http://127.0.0.1:7970 을 연다.

바꿀 수 있는 것: `PORT`, `HOST`, `SOCRATES_EFFORT`(low · medium · high, 기본 medium), `SOCRATES_PASSWORD`(있으면 처음에 비밀번호를 묻는다 — 다른 사람에게 열 때).

## 두뇌

- 모델 `claude-opus-5-5`, 생각 깊이 medium, 스트리밍(쓰는 대로 화면에 뜬다).
- 거절되면 다른 모델로 이어 가게 했다(`fallbacks: "default"`).
- 시스템 글은 캐시해서, 두 번째 말부터는 싸고 빠르다.
- 11/22 시험: 한 번 답에 3~6초, 출력 200~500 토큰(한 번에 십몇 원 꼴).

## 여러 사람

- 문답마다 번호가 있고, 서버는 번호별로 대화를 따로 쌓는다.
- 지난 문답 목록은 각자의 브라우저에만 남는다(로그인 없음).
- 밖에 열 때는 `SOCRATES_PASSWORD` 로 문을 단다. 비밀번호를 맞힌 브라우저는 180일 동안 다시 묻지 않는다.
